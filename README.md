# 60초 안내 — 다중이용시설 흉기난동 실내 대피 유도 AI

2026 AI 라이프 솔루션 챌린지(산업통상부·KEIT) 출품 시제품.

기존 CCTV가 흉기나 군중 급이탈을 잡으면, 그 카메라가 평면도의 어느 구역인지 찾고,
구역마다 다른 행동(숨기 / 봉쇄 / 대피 / 실내 대기)을 정해 **층별 안내문**과 비상등 방향을 만든다.
탐지부터 첫 안내까지 60초 안이 목표다.

## 구조

```
CCTV 영상 → 탐지 AI(흉기·군중 급이탈) → 위치 매핑(평면도 그래프) → 안내 생성 AI → 층별 방송·비상등·관제 화면
                                        └────── 이번 시제품이 새로 만드는 판단 계층 ──────┘
```

- `src/lib/building.ts` — 가상 3층 복합몰 평면도(노드·엣지·카메라·출구). 실제 시설 데이터가 아니다.
- `src/lib/engine.ts` — 판단 엔진. 위험 노드 → 구역별 행동 + 최단 안전 경로(Dijkstra). 규칙만 쓴다.
- `src/lib/announce.ts` — 안내문. 템플릿 생성기(폴백·테스트 기준)와 생성형 AI용 프롬프트.
- `src/app/api/announce/route.ts` — `ANTHROPIC_API_KEY`가 있으면 생성형 AI로 문장을 만들고, 없거나 실패하면 템플릿.
- `src/components/` — 관제 화면. CCTV 패널(탐지 박스 오버레이), 층별 평면도, 층별 안내문, 타이머 로그.
- `public/detections/*.json` — 카메라별 프레임 탐지 결과. **지금은 플레이스홀더**이며 실제 모델 결과로 교체한다.
- `public/video/*` — CCTV 클립. **지금은 플레이스홀더**이며 공개 데이터셋 클립으로 교체한다.

탐지는 미리 돌려 JSON으로 만들고 화면은 그 JSON을 재생한다. 판단과 안내문 생성은 화면에서 실시간으로 한다.
배포 환경(Vercel)에서 GPU 추론을 돌릴 수 없고, 심사위원이 URL을 열었을 때 설치 없이 바로 돌아가야 하기 때문이다.

## 실행

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # 판단 엔진 테스트
```

환경변수(선택): `ANTHROPIC_API_KEY`, `LLM_MODEL`(기본 `claude-haiku-5-5`). 없으면 템플릿 안내문으로 동작한다.

## 처리 속도 재현 (성과보고서 실험 1)

```bash
npx rolldown scripts/bench-engine.ts --format esm --file /tmp/bench.mjs && node /tmp/bench.mjs
```

24개 구역을 하나씩 위험 위치로 놓고 판단 + 템플릿 안내문을 200회씩 돌린다. 보고서 숫자는 3번 실행(14,400회) 결과다.
생성형 AI 문장은 API 응답을 최대 8초까지만 기다리고, 넘거나 실패하면 템플릿 문장을 낸다.

## 탐지 결과 JSON 스키마

```json
{
  "placeholder": false,
  "camera": "CAM-2F-03",
  "fps": 30,
  "durationS": 14,
  "frames": [{ "t": 0.0, "boxes": [{ "cls": "knife", "conf": 0.87, "x": 0.41, "y": 0.52, "w": 0.05, "h": 0.08 }] }]
}
```

`x, y, w, h`는 0~1 정규화 좌표. `cls`가 `person`이면 회색, 그 외는 흉기로 보고 빨강으로 그린다.

## 시연·캡처

`window.__demo`로 시계를 직접 움직일 수 있어 프레임 단위 캡처가 결정적이다.

```bash
node scripts/shot.mjs http://localhost:3000/ 0,9000,40000   # 지정 시각 스크린샷
```

`?autoplay=1`을 붙이면 로드 뒤 자동 재생.

## 데이터와 영상 원칙

- 학습·테스트 데이터는 라이선스가 확인된 공개 데이터셋만 쓴다. 출처는 여기에 적는다. (추가 예정)
- 실제 사건 영상·사진·피의자 이름은 쓰지 않는다.
